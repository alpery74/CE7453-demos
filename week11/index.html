The grading sheet: one skill, graded token by token or all or nothing

Six models of increasing size answer the same twelve questions. Each answer is a row of tokens, coloured right or wrong. Per-token accuracy rises smoothly with size. Now grade the way leaderboards do, with exact match over the whole answer, and watch where the skill appears to switch on.

Smallest model that will score at least 50 % exact match on 20-token answers:

Per-token accuracy follows p(N) = 0.05 + 0.95 / (1 + exp(-1.5 (log10 N - 9))), a smooth curve with nothing emergent in it. Exact match over L tokens is p^L, which stays near zero until p is close to one and then rises steeply. Schaeffer, Miranda and Koyejo (2023) showed that most reported emergent abilities behave this way under a continuous metric, which is the point of slide 9.

Build the prompt: teach a fixed model a new rule without touching a weight

A model pretrained on many linear rules y = a x + b is asked for y at x = 1.5 under a rule it has never seen. Add worked examples to the prompt by clicking them. The weights, which are the prior over (a, b), never change; only the context does. Get within 0.10 of the truth with as few examples as you can.

The model here is Bayesian linear regression with a Gaussian prior on (a, b) standing in for pretraining. Each example in the prompt conditions the posterior in closed form; the completion is the posterior predictive mean. Nothing is gradient-updated, which is slide 11's claim that in-context learning is inference. Two well-spread examples pin the slope; four clustered ones do not, which is slide 12's point about what makes a good prompt.

Each task's true update is built from singular values that decay geometrically, fast for a narrow task and slowly for a broad one. The rank-r adapter keeps the first r directions, so the relative error is the energy in the tail. LoRA's premise on slide 16 is that real fine-tuning updates have the fast-decaying kind of spectrum; the bench shows what happens when they do not.
